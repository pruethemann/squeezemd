# auxillaryscripts/ — experimental helper scripts

Ad-hoc, **unmaintained** helper scripts (PyMOL macros, distance/free-energy
analyses) used during development. They are **not** part of the installed
`squeezemd` workflow and are not invoked by the Snakefile or any console entry
point.

Kept for reference only; intentionally excluded from linting and not covered by
tests. Use them as a starting point, not as a supported interface.
